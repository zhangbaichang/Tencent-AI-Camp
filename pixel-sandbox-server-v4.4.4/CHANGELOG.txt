Pixel Sandbox HTML V4.3.1 — 2026-10-01
基线：用户提供的 pixel-sandbox-server-v4.3.0-mobile-inventory-final.zip。
仅升级 HTML/Node 网页版，不涉及 Java/LibGDX。

修复页面末尾损坏的 script 标签，停用两套未接入实际槽位的旧补丁。
修复拖拽浮层缺少 canvas，使用真实物品图标、数量、阴影和目标槽位高亮。
统一 Pointer Events：触屏按住 240ms 拿起，直接滑动滚动，鼠标拖动或点击搬运。
按 pointerId 隔离多指操作，支持取消、窗口失焦和关闭界面恢复物品。
修复背包交换被自动排序撤销、快捷栏重复计数、箱子取物函数缺失。
支持箱子/背包转移、同物合并、异物交换和满背包回退；保持快捷栏引用模型。
新增现有护甲系统的背包装备槽与卸下按钮，装备结果由服务端确认并同步数量。
修正手机设置/聊天/背包按钮布局，横屏采用横向布局，保留挖掘/放置/跳跃按钮。
静态资源限制为公开页面与资源，拒绝下载后台源码、账户数据、存档及路径穿越。
新增自动回归测试、版本说明和部署入口。

边界：沿用按物品 ID 汇总数量的背包模型，不引入每格 64 件或拆分堆叠。
装备栏沿用原版单一护甲槽，不虚构头盔/鞋子等尚未实现的装备类型。
本版聚焦手机交互；完整管理后台、怪物服务器化等属于后续阶段。
