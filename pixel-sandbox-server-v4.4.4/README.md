# Pixel Sandbox HTML V4.4.2

基于上传的 V4.3.0 完整源码升级，网页客户端入口 `index.html`，服务端入口 `server/server.js`。

## 启动

安装 Node.js 24 或以上，在项目根目录执行 `node server/server.js`，访问 `http://localhost:8080`。
发行包包含纯 JavaScript 的 ws 依赖；如需重装，在 server 目录执行 `npm install`。
Windows 双击根目录 `start.bat`（菜单含 安装/启动/停止/重启/状态/备份/查Frp；直接运行 `start.bat start` 可一键前台启动）。Linux 运行 `bash start.sh`（默认一键启动，支持 `install/stop/restart/status/frp` 子命令）。
生产部署通过 OP_PASSWORD 环境变量设置管理密码。PORT 默认 8080。管理入口 `/op`。

## 操作

- 手机：直接上下滑动滚动背包，按住物品 240ms 再拖动，松手放入高亮槽位。
- 电脑：拖动物品，或点击拿起、再点击目标槽位。拖到面板外取消。
- 背包与快捷栏共享物品数量；快捷栏是引用，不是另一份物品。
- 箱子物品可拖到左侧“放回背包”，同类物品合并。背包空间不足时自动扩展。
- 护甲拖到护甲槽后由服务器装备；“卸下”返回背包。

## 升级与存档

先停止旧服务并备份整个旧目录。在新目录解压本发行包后，将旧服 `server/data/`、`server/world/`、`server/players.json` 复制到新目录对应位置，再启动。
源码目录保留上传包中的原数据；发布 ZIP 不包含账户、历史玩家、权限表、后台日志或世界存档，防止把原服私人数据分发出去。未迁移数据时首次启动生成新世界。
旧版备份不要删除，回退时恢复旧程序与对应备份。不要让两套服务同时写同一份存档。

## 验证

执行 `npm test`。测试使用隔离的临时服务与测试账号，不修改你的正式存档。
自动测试覆盖物品转移、槽位交换、取消恢复、滚动识别、多指隔离、HTTP 启动、注册和 WebSocket 握手。
尚需在 Android 和 iPhone/iPad 真机上验收触控与软键盘；本版不宣称已完成所有设备验证。
未来阶段和已知限制见 CHANGELOG.txt。现有 HTTP 轮询动作鉴权及客户端上报背包仍需后续专项加固，本版不是完整反作弊升级。

## V4.3.3 自动扩展背包

生存模式36格为起始容量，不再是上限。新增物品种类超出时自动补充槽位，向下滚动可查看全部物品。已有存档中超过36种的物品会自动显示；整理好的位置保留，槽位不自动缩小。升级时保留原服数据，并重启服务器、刷新页面。

## V4.4.0 箱子密码、共享丢弃物和坐标

- 新放置的箱子归放置账号所有；旧箱子首次打开时确定管理账号。所有者可在箱子界面设置/修改密码，或取消密码。不设置密码时任何附近玩家可打开。
- 密码为4至128个字符，以加盐 scrypt 哈希保存。输入正确密码可打开箱子；关闭、切换到其他面板、断线或解锁凭证超时后，需要重新输入密码。密码保护是服务器访问控制，存档内容本身不是加密密文。
- 箱子内容保存到 server/data/chests.json，一次允许一个玩家操作。请把整个 server/data 目录纳入备份。原版箱子内容只在各自客户端内存中，没有服务端存档可供自动迁移；更新前请先取出旧箱子物品。
- 已登记箱子不能直接挖掉。所有者打开并取空箱子后，点击“拆除空箱”收回箱子。加密箱子需要先输入密码打开。
- Q键、手机丢弃按钮和背包垃圾桶丢出的普通物品会共享给在线玩家，由服务器决定谁拾取成功，60秒后消失。新加入玩家也能看到尚未消失的共享物品。共享物品按玩家朝向抛出，由服务器统一计算重力、墙面碰撞、落地与减速，客户端平滑显示运动。
- 硫磺弹和闪光弹仍会引爆，每次投掷1件，已点燃的投掷物不能拾取。
- 左侧显示玩家脚下方块坐标。左上为原点，X向右、Y向下，不是海拔或像素坐标。
- 箱子和共享物品需要连接服务器。掉落物不跨服务器重启保存。背包整体仍沿用客户端上报模型，本次没有重写全部反作弊系统。
- 本次验证包含两个真实 WebSocket 客户端的联机测试，尚未完成手机真机界面验收。

## V4.4.1 修复

加密箱子仍对所有玩家可见（包括之后加入的玩家），只有打开需要密码。密码不隐藏箱子方块。
修复手机摇杆小幅向左时丢弃方向错误；丢弃方向跟随人物朝向，不固定朝右。
恢复丢弃物抛物线、重力、碰墙和落地，普通物品落地后停止悬浮。服务器读取与客户端相同的世界生成数据及方块改动进行碰撞检测。
首次启动需要生成用于物理碰撞的基础地形，请等待启动日志显示就绪。原有箱子密码与内容仍保存在 server/data/chests.json，升级保留整个 server/data 和世界存档。

## V4.4.2 坐标和人物朝向

管理面板与游戏使用同一坐标函数：X=floor((像素x+角色宽度/2)/24)，Y=floor((像素y+角色高度)/24)，即脚下中心所在方块。
面板刷新有短暂延迟，移动时可能与当前帧差少量格数；停止后两端应一致。网络位置仍以像素传输，不改动旧存档。
本机与远端玩家均整个人物左右镜像，名字保持正向；键盘方向优先于残留摇杆输入，松开后保持最后方向。
升级后重启服务器，并同时强制刷新游戏页面和管理面板，加载新增的 player-view.js。
