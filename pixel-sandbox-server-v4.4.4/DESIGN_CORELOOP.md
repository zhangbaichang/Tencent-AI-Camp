# 像素沙盒 · 核心循环与验证设计（草案 v0.1）

> 视角：系统思维拆解。把「好玩」翻译成可测量的源/汇与数值验证路径。
> 概念定位假设：同种子联机沙盒生存——「赤手进入共享荒野，亲手把矿物变成武器，再带武器征服更深的黑暗」。
> （若你的概念定位不同，指出后我重写第 0/1 节。）

---

## 1. Fun Hypothesis（乐趣假设）

**一句话**：玩家会从 `挖矿 → 熔炼 → 合成 → 战斗 → 探索` 这条**亲手转化链**获得心流，因为每一步都把「世界里的资源」变成「我身上的能力」；而多人同世界让这份成长被看见、被抢、被讲述。

> 乐趣 = 转化掌控感 × 社交涌现

**可证伪条件（怎么算验证失败）**：
- 若玩家拿到铁剑后，仍 80% 时间在挖同一种地表矿、且不再主动下地下 → 假设中「转化→更强挑战」的驱动力失效，需重做地下奖励曲线。
- 若多人局里所有人各挖各的、零交互 → 「社交涌现」失效，需加共享目标（如据点/ boss 争夺）。

---

## 2. Design Pillars（设计支柱，5 条）

- **P1 亲手转化的掌控感**：你手里的每件工具/武器，源头都是你挖的矿。系统不送成品装备。
- **P2 动词职责分明**（本条即你纠正的点）：
  - **熔炉 = 熔炼**（热转化）：矿 → 锭、锭 → 合金。只改变物质的「纯度/形态」，不做组装。
  - **工作台 = 合成**（组装）：锭 + 部件 + 消耗品 → 工具 / 剑 / 闪光弹等。
  - 两个动词**不重叠**，降低认知负荷；合金不能在工作台做，必须先在熔炉熔。
- **P3 世界是共享舞台**：同种子世界 + 服务端权威同步，成长可见、可被掠夺、可被讲述。
- **P4 有代价但可恢复**：死亡掉落惩罚制造风险，60s 拾取窗口 + 重生保证循环不断。
- **P5 地下是另一个游戏**：地表求生 vs 地下战斗，两条难度/反馈曲线分开设计。

## 3. 核心循环拆解

### 宏观循环（跨局 / 跨天）
```
探索地表 → 挖矿 → 回基地(熔炼+合成) → 武装 → 下地下打强怪 → 掉稀有 → 更强装备 → 回到探索
```

### 微观循环（单次会话内）
```
选目标 → 采集/战斗 → 处理(熔炉/工作台) → 得产出 → 应用产出 → 反馈 → 选更高目标
```

### 处理环节的双节点（源 → 汇）
```
熔炉(熔炼) :  矿石 ──[热]──▶ 锭 ──[热]──▶ 合金(黄铜/不锈钢)
工作台(合成): 锭 + 部件 + 消耗品 ──[组装]──▶ 工具 / 剑 / 闪光弹
```
**关键约束**：合金必须先在熔炉熔；闪光弹 = 镁锭 + 硫磺在**工作台**合成（不是熔炉）。熔炉只认「热转化」，不认「组装」。

---

## 4. 经济系统：源与汇（为数值铺路）

**源（Sources）**：地表矿脉（铝/锌/镍/钛/镁）、树木、地表生物掉落、地下强怪掉落（稀有）。
**汇（Sinks）**：熔炼/合成消耗、武器耐久损耗、死亡掉落、闪光弹/氢气等消耗、建造消耗。

> 平衡铁律：每个「汇」必须对应一个**可控速率的源**供给，否则出现通胀（资源烂大街）或枯竭（卡死进度）。
