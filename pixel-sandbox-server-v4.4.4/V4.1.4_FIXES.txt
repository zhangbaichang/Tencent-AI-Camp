Pixel Sandbox V4.1.4

修复：
1. Windows/桌面电脑误判手机端：桌面精确指针优先，增加 desktop-device CSS 兜底。
2. 吃面包后背包/热栏不同步：服务器现在立即发送 inventory_update。
3. 食物按键增加冷却并避免 UI 打开时误触。
4. 世界渲染缓存：resize / 重新生成世界时立即清空缓存，避免旧缓存覆盖造成闪屏。
5. 世界生成增加 token 防并发旧世界回写。
6. 闪光弹白闪由强烈全屏 0.95 降为柔和 0.28，并快速衰减，减少频闪。
7. 修复创造模式：管理员创造模式现在真正可用并可持久化；开发者默认创造。
8. 创造模式支持自由飞行、无限物品、放置不消耗。
9. 管理中心增加普通玩家/管理员/开发者身份管理与生存/创造模式管理。
10. 管理员创造模式重启后保持；开发者始终创造。
11. 在线玩家表直接提供身份和模式下拉控制。
