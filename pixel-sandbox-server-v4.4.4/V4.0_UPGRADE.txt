Pixel Sandbox V4.0 更新说明

1. 首次运行自动生成世界 Seed，保存到 server/data/world-seed.json；后续启动保持不变。
2. 玩家新增饱食度、护甲、经验、等级与服务器同步。
3. 食物：苹果、面包、熟肉、黄金苹果；支持服务器权威食用与饥饿伤害。
4. 护甲：铁头盔、铁胸甲、钻石胸甲；服务器参与伤害减免。
5. 死亡掉落：管理面板可开关 deathDrop；关闭时死亡不会扣除背包物品。
6. PVP：服务端实际计算护甲减伤并扣除生命。
7. 核工业基础：铀矿、浓缩铀、核燃料棒、核反应堆、冷却液及合成配方；管理面板可关闭核工业。
8. 手机/平板：触控点、coarse pointer、iPadOS 桌面 UA、Windows 触屏平板均进入触屏 UI，并尝试锁定横屏。
9. 管理面板：服务器状态、Seed、在线玩家属性、PVP/死亡掉落/饱食度/核工业/移动端优化等规则控制。

部署：Windows Server 2016 + Node.js + 宝塔 + SakuraFrp 保持原部署方式。
注意：本环境没有项目 node_modules/ws，因此进行了源码语法检查，但未执行真实 WebSocket 运行测试；服务器部署时执行 server 目录 npm install。
