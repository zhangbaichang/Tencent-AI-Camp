像素沙盒 · 联机（WebSocket）配置说明
问题：网页能打开，但游戏一直“正在连接…”，多人联机失败。
原因：你是用【域名】访问的，中间走了宝塔 Nginx 反向代理。
      Nginx 默认不会转发 WebSocket 的升级请求，所以 WS 握手被挡掉。
      网页是普通 HTTP 所以正常，联机是 WS 所以连不上。
解决：给 Nginx 反代加上 WebSocket 支持（见同目录 nginx-pixel-sandbox.conf）。
====================================================================

【方案 A：用宝塔面板（最省事，推荐）】
----------------------------------------
1. 打开宝塔面板 → 左侧「网站」→ 点你的游戏站点 →「设置」→「反向代理」。
2. 找到指向  http://127.0.0.1:8080  的那条代理，点「配置文件」（或「编辑」）。
3. 把里面的 location / { ... } 整段，替换成配套 .conf 里【片段 A】的内容。
   （核心就是这三行：
     proxy_http_version 1.1;
     proxy_set_header Upgrade $http_upgrade;
     proxy_set_header Connection "upgrade";  ）
4. 保存，按提示「重载 Nginx配置」。
   ★ 新版本宝塔的反向代理界面里有一个「启用 WebSocket 支持」勾选框，
     直接勾上即可，等效于手动加上面三行。
5. 刷新游戏页面，应该显示“已连接”，多人能互见。

【方案 B：不用宝塔，直接改 Nginx 配置】
----------------------------------------
1. 把配套 .conf 里【片段 B】的 server 块（HTTP 或 HTTPS 版）粘进你的站点 conf。
2. 把 your.domain.com 换成真实域名；HTTPS 版记得改证书路径。
3. 服务器上执行：
     nginx -t          # 检查语法
     nginx -s reload   # 重载
4. 刷新游戏验证。

【快速自检：先确认就是 Nginx 的锅】
----------------------------------------
在浏览器直接访问：  http://服务器公网IP:8080
  - 如果这个地址能进游戏且能联机  →  100% 是 Nginx 没放行 WS，按上面改。
  - 如果这个地址也联不上          →  问题在 node / 防火墙，再看下方。

【如果直连 IP:8080 也联不上（排除 Nginx 后）】
----------------------------------------
在【服务器】上执行：
  pm2 status                          # 确认 pixel-sandbox 在运行
  ss -tlnp | grep 8080               # 确认 8080 在监听
  curl -I http://127.0.0.1:8080      # 本机能访问说明服务是好的
  firewall-cmd --list-ports          # 看 8080/tcp 是否放行
                                         没放行就：
                                         firewall-cmd --zone=public --add-port=8080/tcp --permanent
                                         firewall-cmd --reload
  # 云厂商（阿里云/腾讯云等）安全组也要放行 8080 入站
  # 另外确认 node 监听的是 0.0.0.0（server.js 里 server.listen(PORT) 默认即全网卡，无需改）

【验证成功的标准】
----------------------------------------
- 游戏内提示“已连接”（不再“正在连接…”）
- 开两个浏览器窗口能互相看到对方角色移动、挖/放方块同步
- 浏览器 F12 → Network → 筛选 WS，能看到状态码 101 Switching Protocols
